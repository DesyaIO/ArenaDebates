# LearningDialog

Учебная сцена: `Assets/Scenes/LearningDialog.unity`.

- Открывается после завершения теории в LearningScene. Выбранный метод передаётся через `SceneParams.SelectedLearningMethod`.
- При прямом запуске используется `Default Method` на объекте `LearningDialogSystem`.
- `Practice Turns` задаёт число ответов в тренировке; по умолчанию 3.
- `LearningDialogController` управляет записью, запросами и отдельной учебной сессией. Сохранённая сессия свободного диалога не изменяется.
- `LearningDialogCoach` формирует промпт и проверяет JSON: оценка игрока, пример улучшения, реплика оппонента и подсказка приходят одним запросом.
- `LearningDialogView` связан с текстами и кнопками сцены. HintText и FeedbackText — обычные редактируемые TMP-объекты.
- Настройки API остаются на объекте DeepSeekClient. Генерация начинается только после нажатия «Новая тренировка». Автоматических платных повторов нет.
- Неясная расшифровка не меняет HP и число попыток. Первый пример оппонента тоже не наносит урон. Дальнейший урон/лечение берётся из AnswerTypes.
- Вёрстка 1080×1920 целиком вписывается в окно; в landscape остаются боковые поля.

## Проверка в Unity

1. Выйти из Play Mode и открыть LearningDialog после импорта новых скриптов.
2. Начать тренировку: проверить метод, тему, позиции, первую подсказку.
3. Записать реплику: проверить расшифровку, разбор, пример улучшения и следующую подсказку.
4. Проверить пустую запись, ошибку API и ручной повтор. HP не должны меняться без принятого ответа.
5. После трёх принятых реплик проверить итог и повторную тренировку.
6. Проверить 1080×1920, 1920×1080 и Free Aspect.

Проверки в `Tests.csproj` запускают реальную логику контроллера и тренера с подменёнными Unity/API-зависимостями. Они не заменяют проверку микрофона, рендера и реального ответа сервиса.
